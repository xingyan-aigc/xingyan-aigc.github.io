    哪些小说会进入库？

    来源与等级
    红果漫剧 IP 库中的潜力 IP，体裁为网文小说。
    全文字数
    5 万—50 万字，包含上下限。
    上架状态
    已上架漫剧数为 0；被挑选次数记录展示，不设硬门槛。
    题材与状态
    男频、女频及题材不限；连载与已完结均纳入。
    评分与在读
    不设采集门槛，按实际值保存，后续参与综合评分；缺失不伪造。

    正文怎么采，如何避免重复？

    可读范围
    采完当前账号在 IP 库可读目录里的全部章节，不固定三五章或 20 章，不转去番茄采正文。
    目录核对
    按章节 ID 核对目录与存档；缺章、无目录和读取失败分别记录，未采齐不作为完整样本评分。
    去重与复用
    按作品 ID、章节 ID 去重；已分析且正文版本未变时复用原分析，平台指标可单独更新。
    新增与异常
    新开放章节增量采集；失败有限重试并保存进度，后续可续采，不无限重试。
    来源留存
    保存原始正文、作品与章节 ID、来源 URL、采集时间及可取得的数据日期，保留版本。

    正文评价基于当前 IP 库可读章节。综合分直接用于排名；具体判档、原文证据与计算过程见各本报告。
